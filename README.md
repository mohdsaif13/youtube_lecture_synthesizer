# 🎓 YouTube Lecture Synthesizer

> A complete, production-ready Streamlit application that transforms any public YouTube lecture into publication-quality lecture notes: extracting presentation slides with Computer Vision (SSIM), reading slide text and formulas via OCR, transcribing spoken audio, synchronizing speech to visual content, and synthesizing structured notes into a downloadable PDF.

## 🔍 Code Review & Verification Summary

An exhaustive review of the codebase was conducted across security, error resilience, and formatting boundaries:

| Area | Review Finding | Status / Resolution Applied |
| :--- | :--- | :--- |
| **ReportLab XML Parsing** | Raw text from YouTube titles, OCR, and presenter names containing `&`, `<`, or `>` could cause `xml.parsers.expat.ExpatError` in `Paragraph`. | **Fixed**: Added `escape_xml()` and `format_markdown_for_reportlab()` functions. All text inputs are sanitised before PDF generation. |
| **Markdown to PDF Formatting** | Synthesized notes generated by LLMs use Markdown (`**bold**`, `*italic*`, `` `code` ``). | **Enhanced**: Markdown tags are safely parsed and translated to ReportLab XML tags (`<b>`, `<i>`, `<font name="Courier">`). |
| **OCR Binary Auto-Discovery** | Windows environments frequently install Tesseract outside system `PATH` (`C:\Program Files\Tesseract-OCR`). | **Resolved**: Automated recursive path resolver searches 4 standard Windows and Unix paths; custom path override added to the sidebar. |
| **Audio Transcription Reliability** | YouTube videos without captions previously risk pipeline interruption. | **Hardened**: Tiered fallback automatically switches from `youtube-transcript-api` to native audio extraction via `yt-dlp` + `faster-whisper`. |
| **Slide Extraction Performance** | Comparing full 1080p frames is CPU-intensive and susceptible to webcam noise. | **Optimised**: Downsamples frames to $320 \times 180$ grayscale for SSIM, debouncing rapid transitions with a minimum duration filter while saving the master frame at native 720p. |
| **Offline Testability** | Requiring an active paid API key prevents immediate zero-cost evaluation. | **Included**: Offline Synthesis Mode generates structured notes from OCR and transcripts without an API key. |

## 🚀 Deployment Options

### Option 1: Docker & Docker Compose (Recommended, Zero-Friction)

The application includes a production `Dockerfile` that bundles Python 3.11, Tesseract OCR, FFmpeg, and OpenCV runtime libraries in a container.

1. Start with Docker Compose:
   ```bash
   docker compose up --build -d
   ```
2. Open your browser at `http://localhost:8501`.

Deploy as a managed serverless web app on Google Cloud:

```bash

# 2. Or deploy directly from source:
gcloud run deploy youtube-lecture-synthesizer \
    --source . \
    --region us-central1 \
    --platform managed \
    --allow-unauthenticated \
    --port 8501 \
    --memory 2Gi \
    --cpu 2
```

## 🧩 Modular Architecture (`app.py`)

| Function | Purpose & Workflow |
| :--- | :--- |
| `extract_slides(...)` | Streams 720p video with `yt-dlp`, samples frames every $N$ seconds with OpenCV, compares consecutive frames using Structural Similarity Index (`skimage.metrics.ssim`), and saves unique keyframes. |
| `get_transcript(...)` | Primary: Fetches timestamped captions via `youtube-transcript-api`. Fallback: Downloads native audio and transcribes with `faster-whisper` or local `whisper`. |
| `run_ocr(...)` | Preprocesses slide images (contrast enhancement, inversion for dark mode), auto-detects Tesseract binary, and runs OCR to extract bullet points, formulas, and slide titles. |
| `synthesize_notes(...)` | Synchronizes each slide's time span $[T_k, T_{k+1})$ with spoken audio transcript segments, prompts the LLM (`google-genai` or `openai`), and formats Key Concepts, Explanations, Code, and Remarks. |
| `generate_pdf(...)` | Uses ReportLab to generate a multi-page document featuring a Title Page, Table of Contents, High-Res Slide Screenshots, OCR Text callout boxes, and two-pass dynamic `NumberedCanvas` ("Page X of Y"). |

## 💡 Key Features Explained

### 1. Robust SSIM Slide Change Detection
Instead of sampling every single frame (which creates thousands of duplicates), `extract_slides()` samples frames every $N$ seconds (default: 2.5s) and resizes them to a standard comparison matrix ($320 \times 180$) to compute SSIM:
- $\text{SSIM} \ge 0.82$: Continuous slide (presenter moving slightly, laser pointer).
- $\text{SSIM} < 0.82$: Slide transition detected! A high-resolution JPEG is preserved as a new keyframe.
- **Debounce:** Enforces a minimum slide duration (default: 3.0s) to prevent intermediate animation frames from cluttering notes.

### 2. Multi-Tier Transcript Fallback
1. **Tier 1:** Native manual English subtitles from YouTube.
2. **Tier 2:** YouTube auto-generated captions.
3. **Tier 3:** Non-English caption translation to English.
4. **Tier 4 (Fallback):** Native audio download via `yt-dlp` and timestamped transcription via `faster-whisper` (int8 quantized on CPU) or standard `whisper`.

### 3. Publication-Grade PDF Layout
- **Title Cover Page:** Formatted with document banner, lecturer name, video metadata, and date.
- **Dynamic Two-Pass Canvas:** Uses ReportLab's `NumberedCanvas` pattern to render running headers and exact total page counts (`Page 4 of 18`).
- **Clean Sectional Hierarchy:** Verbatim on-slide text is isolated in light-gray callout blocks, while the teacher's verbal elaboration is rendered in clear academic typography with bullet points and bold headers.

## 🛠️ Troubleshooting & FAQ

#### 1. "ERROR: unable to download video data: HTTP Error 403: Forbidden"
- **Why this happens:** When deployed to cloud providers (Streamlit Community Cloud, AWS, GCP, Hetzner), YouTube's anti-bot system detects datacenter IP addresses and blocks web video streams with `HTTP 403 Forbidden`.
- **How to resolve:**
  1. **Option A (Zero Setup, Recommended):** In the web UI, click the **"📁 Upload Lecture Video File"** tab and upload your `.mp4` video directly. This processes the slides locally on the server without needing to stream from YouTube!
  2. **Option B (Automatic Client Fallback):** The latest code automatically rotates client signatures (`android`, `ios`, `mweb`, `tv_embedded`) and forces IPv4, which bypasses 403 errors on many cloud hosts.
  3. **Option C (Cookies in Streamlit Secrets):** Export cookies from your browser (using extensions like *Get cookies.txt LOCALLY*) and add them to your Streamlit Cloud **Secrets**:
     ```toml
     YOUTUBE_COOKIES = """
     # Netscape HTTP Cookie File
     ...
     """
     ```
  4. **Option D (Run Locally):** Run the application on your computer using `deploy_local.bat` or `streamlit run app.py` where your residential IP address is not blocked by YouTube.

#### 2. "Tesseract OCR executable not found"
- If running natively, ensure Tesseract is installed (`winget install UB-Mannheim.TesseractOCR` or `brew install tesseract`).
- Or run via Docker (`docker compose up`), where Tesseract is pre-configured.

#### 3. "Captions not found for this video"
- The app automatically switches to downloading the audio and transcribing locally with Whisper if `faster-whisper` is installed.

#### 4. "HTTP Error 429: Too Many Requests" from YouTube
- YouTube occasionally rate-limits automated IP requests.
- Use the quick sample buttons provided in the UI (CS50, 3Blue1Brown, MIT OCW) or upload a video directly.
